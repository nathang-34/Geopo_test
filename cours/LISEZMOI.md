# Photos de cours

Dépose ici les photos de ton cahier de cours, **un sous-dossier par chapitre**.

Exemple :

```
cours/
  1939/
    page-01.jpg
    page-02.jpg
  guerre-froide/
    page-01.jpg
```

## Comment déposer des photos sur GitHub

1. Ouvre le dépôt sur GitHub, puis le dossier `cours`.
2. Clique sur **Add file** puis **Upload files**.
3. Sur ton PC, range d'abord tes photos dans un dossier au nom du chapitre (par exemple `1939`), puis **glisse ce dossier entier** depuis l'explorateur Windows dans la zone de dépôt : GitHub garde le nom du dossier.
4. En bas, clique sur **Commit changes**.

Ensuite, demande à Claude (dans Claude Code) : « Traite les photos de `cours/1939` ». Il créera le fichier `imports/1939.json`, à charger dans le site (page Importer, bouton « Charger un fichier »).

⚠️ Le dépôt est public : ces photos sont visibles par tout le monde.
