# Fichiers d'import

Ce dossier contient les fichiers JSON créés par Claude à partir des photos du dossier `cours/`, au format `geopo-import` (voir `AVANCEMENT.md`).

## Les charger dans le site

1. Récupère la dernière version du dépôt (bouton vert **Code** puis **Download ZIP** sur GitHub) et décompresse-la.
2. Ouvre le site, page **Importer**.
3. Clique sur **📂 Charger un fichier** et choisis le fichier voulu dans ce dossier `imports`.
4. Vérifie l'aperçu, puis clique sur **Importer la sélection**.

Recharger un fichier déjà importé ne crée pas de doublons : le site les signale et les décoche.
